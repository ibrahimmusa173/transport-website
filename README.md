# 🚛 Dynamic Leo Transport - Logistics Website

Dynamic Leo Transport (DLT) is a high-performance, responsive business website built to showcase logistics and transportation services across the UAE. From construction material supply to specialized water transport, the platform offers a seamless user experience with modern animations and a mobile-first approach.

## 🚀 Tech Stack
* **Frontend Library:** React 18
* **Build Tool:** Vite 5
* **Styling:** Tailwind CSS 3
* **Routing:** React Router 7
* **Animations:** AOS (Animate On Scroll) & Framer Motion
* **Icons:** FontAwesome 6 & Lucide React

## ✨ Key Features

### 🏗️ Specialized Service Pages
Custom-built landing pages for core business sectors:
* **Cargo Transport:** Light & Heavy truck solutions with step-by-step process guides.
* **Construction & Demolition:** Sustainable waste management and recycling solutions.
* **Material Supply:** Catalog for aggregates, sands, and natural rocks.
* **Water Transport:** Dedicated pages for drinking and bulk water delivery.

### 🎨 Modern UI/UX
* **Video Hero Background:** High-quality transport video background for immediate engagement.
* **Responsive Navigation:** Intelligent Desktop & Mobile navbars with active-link tracking.
* **Interactive Components:** Auto-scrolling Partner logo slider and animated client testimonials.
* **Floating WhatsApp Integration:** Direct click-to-chat button for instant customer inquiries.

### 🛠️ Technical Highlights
* **Animate On Scroll (AOS):** Smooth fade-up effects as users browse the content.
* **Custom Tailwind Animations:** Hand-crafted keyframes for the partner loop and "tilt-shaking" effects.
* **SEO Friendly:** Semantic HTML5 structure and clean metadata.
